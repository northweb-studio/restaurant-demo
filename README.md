# Restaurant Demo

A modern restaurant demo website built with React and TypeScript.

## Features

- Modern responsive design
- Restaurant menu
- Hero section
- About section
- Gallery
- Contact section
- Mobile friendly
- Fast and clean UI

## Technologies

- React
- TypeScript
- Vite
- CSS

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
